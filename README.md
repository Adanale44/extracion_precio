# Bitacora

- Crear un archivo .gitignore para proyectos en python
- Crear un entorno virtual con el comando : "pipenv shell"
- En el archivo Pipfile estan los paquete que se intalaron para este proyecto en particular con el comando : "pipenv install bs4" . Para volver a instalar estos paquete usamos los comandos : "pipenv install"
- para todo programador el primer archivo es "main.py" en tando el proyecto sea en python, esto se usa para ejecutar toda la aplicacion
